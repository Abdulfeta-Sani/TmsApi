# Conclusion

The API versioning middleware behaves as expected.

* V1 endpoints are marked as deprecated.
* V2 endpoints are the current supported version.
* Deprecation headers are only returned for V1.
* V2 exposes the new response contract (`data`, `meta`, `links`) with no deprecation metadata.
